# Ranked Choices – Product Requirements Document (PRD)

## 1. Product Vision
Ranked Choices is an offline-first web application that enables users to create ranked lists based on custom criteria with numeric weights (0–10).

## 2. Target User
Individuals making structured decisions (e.g., salary allocation, purchases, priorities).

## 3. Core Features (V1)
- Unlimited lists
- Up to 20 criteria per list
- Up to 100 items per list
- Manual ranking mode
- Criteria-weighted automatic ranking mode
- Toggle between manual and weighted ranking
- PWA (offline-first)
- IndexedDB persistence

## 4. Non-Goals (V1)
- Collaboration
- Cloud sync
- Sharing/exporting
- Authentication
- Analytics

## 5. Success Criteria
- Stable offline functionality
- Deterministic ranking algorithm
- No state inconsistencies
- Clean UI with predictable UX
