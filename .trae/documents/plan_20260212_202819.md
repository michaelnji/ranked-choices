# Ranked Choices Implementation Plan

Based on the `AI-CODE-GENERATION-PROTOCOL.md` and project documentation, here is the comprehensive implementation plan.

This plan is strictly divided into the 5 phases defined in the protocol. Each phase must be fully completed and verified before moving to the next.

## Phase 0: Foundation
**Goal**: Initialize project structure, align dependencies with the protocol, and set up core capabilities (PWA, DB).

1.  **Clean & Align Dependencies**
    *   Remove `primevue`, `@primeuix/themes`, `primeicons`.
    *   Install `daisyui` and add to Tailwind config.
    *   Install `shadcn-vue` (or setup utils for it) and required icons.
    *   *Goal*: Ensure the stack matches the Protocol explicitly.

2.  **PWA Configuration**
    *   Install `@vite-pwa/nuxt`.
    *   Configure `nuxt.config.ts` with PWA manifest (Name: "Ranked Choices", "offline-first" strategy).
    *   *Success Metric*: Application installs as PWA and works offline (basic load).

3.  **IndexedDB Scaffold**
    *   Install `dexie`.
    *   Create `utils/db.ts` to initialize the database connection.
    *   *Success Metric*: Database initializes without errors in the browser console.

4.  **Layout & Router Setup**
    *   Create `layouts/default.vue` with a basic shell (Header, Main, Footer).
    *   Ensure `pages/index.vue` renders correctly.
    *   *Success Metric*: App runs locally with new styling stack.

## Phase 1: Data Model + Storage
**Goal**: Define strict types and implement the persistence layer.

1.  **Type Definitions**
    *   Create `types/index.ts` with `List`, `Criteria`, and `Item` interfaces.
2.  **Database Schema**
    *   Update `utils/db.ts` to define tables/stores.
3.  **CRUD Composables**
    *   Create `composables/useLists.ts` and `composables/useListDetails.ts`.
    *   *Success Metric*: Can programmatically create a list, add items, and reload page to see data persists.

## Phase 2: Ranking Engine
**Goal**: Implement the deterministic ranking logic as a pure function.

1.  **Ranking Logic**
    *   Create `utils/rankingEngine.ts` with `calculateScore` and `sortItems`.
    *   Formula: `score = SUM(item_score_for_criterion * criterion_weight)`.
2.  **Unit Testing**
    *   Create `utils/rankingEngine.test.ts`.
    *   Tests for empty criteria, zero weights, max weights, tie-breaking.

## Phase 3: UI Implementation
**Goal**: Build the user interface components and flows.

1.  **Dashboard**: List of lists.
2.  **List Editor**: Tabs for Items, Criteria, Ranking.
3.  **Criteria Management**: Add/Remove, Weight sliders.
4.  **Item Management**: Add items, input scores.
5.  **Ranking View**: Toggle Manual/Weighted, Drag-and-Drop.

## Phase 4: Test Hardening
**Goal**: Validate constraints and edge cases.

1.  **Constraint Enforcement**: Guards for limits (100 items, 20 criteria).
2.  **Integration Testing**: Offline mode verification, state consistency.
3.  **Final Review**: Lint/type-check, no external API verification.
