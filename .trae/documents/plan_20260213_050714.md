# Atomic Spacing Standardization & Navbar Refactor

## 1. Icon-Only Navbar
-   **Modify `app/layouts/default.vue`**: Remove text labels ("Home", "Info") from `.k-nav-btn`.

## 2. Strict 8px Grid System (Standardization)
I will eliminate the arbitrary `12px` (`gap-3`, `p-3`, `space-y-3`) spacing in favor of a strict **8px / 16px / 24px** scale.

### CSS Updates (`app/assets/css/app.css`)
-   **Standardize Padding**:
    -   `.k-card`: `p-3` → `p-4` (16px padding).
    -   `.k-topbar`: `px-4 py-3` → `px-4 py-4` (Consistent 16px vertical/horizontal padding).
    -   `.k-bottom-nav`: `px-4 py-3` → `px-4 py-4`.
    -   `.k-btn`, `.k-input`, `.k-nav-btn`: Ensure consistent `h-12` (48px) or `h-14` (56px) height standards and `px-4` padding.

### Template Updates (All Components & Pages)
-   **Layout Gaps**:
    -   Replace all `gap-3` with `gap-4` (16px) for major component separation (e.g., between cards, list items).
    -   Replace `gap-3` with `gap-2` (8px) for tight internal elements (e.g., icon + text, form labels).
-   **Vertical Rhythm**:
    -   Replace `space-y-3` with `space-y-4` (16px) for card content flow.
    -   Maintain `space-y-6` (24px) for page-level section separation.
